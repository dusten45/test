# Linux 첫 검증판 실행 기록

2026-10-18, Linux x86-64 독립 실행판. Debian 13 클라우드, Xvfb X11, Mesa llvmpipe 소프트웨어 렌더러에서 시험했다. Android OS·에뮬레이터·Android 시스템 이미지는 사용하지 않았다. 시험용으로 새로 만든 저장 데이터만 사용했다.

## 입력과 구현

- 기준 Android 수정 APK SHA-256: `c8211db68b9b093da2ae9a349365063241fd18da286738c563b081fc24c15bfe`.
- dex2jar 2.4의 오류 시 중단 옵션으로 1,176개 클래스를 JVM으로 변환했다. 변환 실패를 실행 시 예외로 대체하는 옵션은 사용하지 않았다.
- 변환된 `game.jar` SHA-256: `30f946aac6d9c440f30c9f0150db0d45a8799475b29c7acae5cad7874f7ec5d6`.
- 원본 리소스 4,760개를 그대로 추출했다. 534개 게임·엔진 클래스의 JVM 검증을 통과했다.
- Linux API 계층이 창·입력·OpenGL·한글 폰트·오디오·XML 저장을 담당한다. 게임 로직과 콘텐츠·해금 조건은 기준 APK의 바이트코드를 따른다.
- 외부 DTD에 접근하지 않는 plist 파서와 렌더링 스레드에 한정된 OpenGL 자원 정리를 적용했다. 원래 게임의 대화상자 버튼 콜백을 보존했다.

## 실제 조작으로 확인한 기능

1. 타이틀과 메인 메뉴, Paladog 캠페인 선택, 빈 슬롯에 새 게임 생성, Easy 난이도, 이야기 화면과 튜토리얼 진입.
2. 한글 튜토리얼·퀘스트·종료 안내 표시. D 키로 캐릭터가 이동해 튜토리얼 깃발에 도착했다.
3. 첫 스테이지 실전 전투에서 이동, `1` 키로 유닛 소환, `Q` 키 마법 효과를 확인했다. 이동과 소환·마법을 함께 사용했다.
4. 게임 종료 확인에서 YES를 눌러 자연스럽게 저장·종료했다. 시간 제한 강제 종료로 대체하지 않았다.
5. 배포 압축을 공백이 있는 별도 경로에 풀고 내장 파일 체크섬을 검사했다. 동봉된 `runtime/bin/java`로 실행한 사실을 프로세스와 `execve` 추적에서 확인했다.
6. 같은 시험 저장 폴더로 실행하자 마지막 전투 이어하기가 표시됐다. YES를 선택해 전투와 유닛을 복원했고, 캐릭터 X 좌표도 저장 당시의 `197.50026`으로 복원됐다.
7. 같은 저장 폴더로 두 번째 프로세스를 실행하자 단일 실행 잠금으로 거부됐다.
8. 이후 플레이 중 캐릭터가 패배해 일반 게임의 Mission Failed와 업그레이드 안내로 진행했다. 안내 완료 후 메인 메뉴로 돌아가 종료 확인의 YES로 배포본도 정상 종료했다. 이는 게임 내 패배이며 프로그램 충돌이 아니다.

원래 게임의 저장 구조를 사용하지만 실제 사용자의 Android 저장 데이터 이전은 시험하지 않았다. 시험 세이브와 원시 실행 로그는 저장소에 넣지 않는다.

## 자동 검사와 오디오

[자동 검사 요약](adapter-tests.txt)의 모든 그룹을 통과했다. 저장 자료형·원자적 쓰기·오류 시 보존·백업 복구, 실제 리소스 접근, plist 814개 오프라인 해석, MP3 145개 디코딩, OpenAL 출력·반복·동시 재생, OpenGL 알파·한글·스레드 정리, 키 입력을 검사했다. 검사 전후 어댑터 클래스 파일이 바뀌지 않았음도 확인했다.

실제 패키지 게임 실행의 OpenAL 출력을 WAVE로 약 367.52초 캡처했다. 48kHz 스테레오 출력에 0이 아닌 오디오 샘플을 확인했다. [오디오 수치](audio-summary.json)는 소리가 생성된다는 근거이며 물리 스피커 청취 결과가 아니다. 캡처 파일 자체는 저장소에 포함하지 않는다.

## 통신 관측

패키지 실행부터 종료까지 `strace`의 `network,execve` 이벤트를 추적했다. [요약](network-summary.json)에서 외부 서버 연결이나 TCP/UDP 송신은 관측되지 않았다. UDP 포트 0 연결 2건은 자신의 인터페이스 주소에 대한 주소 선택·경로 조회였다. 커널 NETLINK 조회와 로컬 X11 연결은 있었다.

이 결과는 시험한 실행 경로에 한정된다. 모든 게임 분기나 일반 `write/writev`, 전체 패킷 캡처를 검증한 것으로 확대하지 않는다.

## 아직 검증하지 않은 범위

실제 Fedora 데스크톱, 물리 GPU·스피커, Wayland 세션의 XWayland, 장시간 플레이, 캠페인 전체, 다크독 전체, 서바이벌 전체, 모든 장비·업그레이드는 미검증이다. 첫 검증판은 Linux x86-64·X11/XWayland·고정 960×640 창을 대상으로 한다. 전체 화면·창 크기 변경·게임패드·Linux ARM·Windows 빌드는 이번 판에 포함하지 않는다.

사용자가 보고한 Galaxy S26·One UI 9.0에서의 약 5분간 정상 실행은 Android 수정본의 별도 관측이다. Linux판의 전수 검증으로 간주하지 않는다.

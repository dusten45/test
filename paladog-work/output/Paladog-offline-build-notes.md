# 팔라독 2.2.0 오프라인 개인정보 보호 수정본

## 파일과 범위

- 파일: `Paladog-2.2.0-offline-privacy.apk`
- 입력 SHA-256: `db9d5c399d7f436a27dba28eebd66771fdc29c812c0e06008c67409bd595a6e1`
- 출력 SHA-256: `92f93b8bf639f1765457d8dd3b83bc440089d4d885c2d244e94445fbc0533213`
- 출력 크기: 40,953,142바이트
- 패키지/버전: `com.Paladog.KorGG`, `2.2.0`, versionCode `25`
- 요청: 게임 콘텐츠와 로컬 저장을 보존하면서 개인정보 조회, 불필요한 외부 통신, 마케팅 동의 화면을 제거.

이 파일은 사용자가 제공한 APK의 개인용 수정본이다. 개발사 공식 원본, 모든 악성 동작 제거 또는 완전한 안전성을 보증하는 파일이 아니다.

## 원본에 관해 직접 확인한 내용

분할 파일을 001→002→003 순서로 재조립한 결과는 41,046,844바이트이고, 입력 해시는 첨부 보고서와 일치했다. ZIP CRC와 APK 서명 검증을 통과했다. 서명 인증서 SHA-256은 `a40da80a59d170caa950cf15c18c454d47a39b26989d8b640ecd745ba71bf5dc`이며 AOSP 공식 미러의 공개 테스트 인증서와 직접 대조해 일치를 확인했다.

실제 DEX에 SMS 마케팅 동의 문구와 거절 분기가 있었다. 거절은 요청을 보내지 않고 다음 로딩 단계로 이동한다. 따라서 해당 경로 자체를 악성 변조의 증거로 단정하지 않는다. 별도로 Naver 동의 화면과 기기/전화번호 등록 요청도 있었다.

입력 APK의 `ServerManagedPolicy.allowAccess()`는 이미 모든 경로에서 허용을 반환한다. 이것은 입력 파일에서 관찰된 상태다. 이번 작업은 해당 정책이나 구매/콘텐츠 해금 조건을 새로 수정하지 않았다. 공식 유료판과의 전체 코드 비교를 수행한 것은 아니다.

## 변경 사항

1. `Paladog.onCreate()`의 전화번호·IMEI 조회를 제거했다. 실제 기기 ID 대신 게임이 원래 지원하는 빈 문자열 경로를 사용하고, 하드코딩된 기본 전화번호도 빈 문자열로 바꿨다. 기종명은 일부 기기별 호환 처리가 사용하므로 로컬에서 유지했다.
2. 라이선스 설정 난독화에 사용하던 Android ID 조회는 비개인 고정 문자열로 대체했다. 기존 초기화 콜백과 DB 검사는 유지했다.
3. SMS 및 Naver 동의 화면 생성, 마케팅 문구, 두 등록 요청을 `LoadingProc()`에서 제거했다. 관련 상태 30–37은 기존 진행 상태 1로 이어진다. 전투 복구에 쓰이는 공통 확인창은 유지했다.
4. 메인 메뉴의 GCM 자동 등록과 Manifest의 푸시 수신기/서비스를 제거했다.
5. 원격 치트 목록 다운로드와 실행 프로세스 목록 조회를 비활성화했다. 로컬 게임 데이터 무결성 검사는 유지했다.
6. 공용 HTTP 다운로드/업로드 함수와 서버 세이브 복원 함수를 명시적으로 비활성화했다. 특히 네트워크 연결 전에 저장 파일을 비울 수 있는 `HttpFileDownload()` 경로도 차단했다.
7. 홍보 배너 처리를 비활성화하고 What’s New·소셜·외부 사이트·예고편 버튼을 숨겼다. 게임 Activity에서 외부 브라우저 등으로 위임하는 실행도 차단했다. 내부 알림·입력 화면은 유지한다.
8. 서바이벌 선택은 기존 해금 조건을 통과한 뒤 기존 오프라인 서바이벌 경로를 사용한다. 진행도·다크독·아이템·유료 콘텐츠 해금 값은 변경하지 않았다.
9. Google Play 결제 연결을 제거했다. 결제 요청은 구매 성공을 만들지 않고 로컬 안내로 종료한다. 연결하지 않은 서비스의 해제도 방지했다.
10. 권한은 `android.permission.VIBRATE`만 남겼다. `INTERNET`, 전화 상태, 계정, 외부 저장소, 결제/라이선스, 푸시 권한을 제거했다. 자동 클라우드 백업을 비활성화하고 런처 외 Activity는 외부에 공개하지 않았다.

오래된 SDK 클래스와 네이티브 라이브러리 전체를 삭제한 것은 아니다. 확인된 게임 측 호출 지점, 등록된 컴포넌트 및 권한을 제한했다. 잔존 SDK 코드의 모든 잠재적 동작을 완전히 증명한 것으로 해석하면 안 된다.

## 저장 데이터 보존

`strUDID`는 저장 암호화 키가 아니라 저장 내용에 포함되는 비교 값이다. 게임 자체의 로더는 현재 ID가 빈 문자열일 때 기기 ID 불일치 표시를 해제하는 경로를 가지고 있다. 이를 사용했으며 저장 클래스, 암호화 함수, `AppDelegate`의 저장 로직은 변경하지 않았다.

현재 저장은 앱 내부 `shared_prefs/PDWXMLInfo.xml`, `PDWXMLSlot0..7.xml`, `PDWXMLBattle.xml` 등에 기록된다. `files/*.sav`는 구형 형식의 읽기 경로다.

새 서명은 기존 설치의 서명과 다르므로 기존 앱 위에 일반 업데이트로 설치할 수 없다. **기존 앱에 진행 데이터가 있다면 먼저 백업하고, 백업 확인 없이 삭제하지 말 것.** 기존 저장 파일의 실제 이전은 별도 시험 대상이다. 빈 ID 처리만으로 모든 구버전 저장의 호환성을 보증하지 않는다.

## 정적 검증 결과

- 이 작업에서 정의한 정적 검사 34개 통과.
- 최종 APK를 다시 분해하고 디컴파일하는 데 성공.
- APK v1/v2/v3 서명 검증과 ZIP 정렬 검사 통과.
- 새 개인용 RSA 3072비트 서명 사용. 공개 테스트 개인키를 재사용하지 않음.
- 서명 파일을 제외하면 실제 APK 내용의 변경은 `AndroidManifest.xml`, `classes.dex` 두 항목뿐이다.
- 나머지 4,767개 항목은 원본과 바이트 단위로 동일하다. 모든 게임 에셋, 리소스 테이블, 리소스 파일, 네이티브 라이브러리를 포함한다.
- 수정 소스는 Manifest와 네 개의 Smali 클래스다. 저장 구조체·암호화·전투 코드의 직접 수정은 없다.

## 실행 검증

이 변형의 앞선 후보(해시 `4f95219c…`)를 네트워크 차단 Android 6 ARM32 환경에서 설치·실행했다. 캠페인 진입·이동·유닛 소환, 오프라인 서바이벌·상점·장비, 저장 후 프로세스 종료·재실행·살아 있는 전투와 유닛 복원을 확인했다. 현재 해시의 변형에는 이후 What’s New 버튼 제거가 추가됐다. 후보 시험과 최종 파일 시험을 구분하며 상세 기록은 `evidence/runtime/legacy-runtime-validation.json`에 있다.

현재 추천 결과물은 별도의 `Paladog-2.2.0-modern-offline.apk`이며 최신 Android 호환 변경과 실행 결과는 `Paladog-modern-build-notes.md`에 기록한다.

## 호환성 및 사용

패키지의 네이티브 ABI는 원본과 같은 `armeabi`, `armeabi-v7a`다. 이번 작업으로 64비트 APK가 된 것은 아니다. 원본의 구형 target SDK도 유지했다. 64비트 전용 최신 기기에서의 직접 설치·실행은 보장하지 않으며, 이 작업에서 특정 갤럭시 모델이나 VPhoneOS를 검증하지 않았다.

개인 계정·개인 자료가 없는 별도 Android 환경에서 사용하는 것을 권장한다. 네트워크 권한 제거는 앱의 일반적인 직접 통신을 차단하지만 모든 취약점이나 권한 상승 가능성까지 보증하는 조치는 아니다.

## 재현과 보관

작업 경로는 `/workspace/paladog-work`다. `input/original.apk`와 `decoded`는 보존돼 있다. `apply_privacy_patch.py`는 원본 해시를 확인한 뒤 별도 `patched` 디렉터리를 생성하며 기존 패치 작업을 덮어쓰지 않는다.

재빌드:

```bash
cd /workspace/paladog-work
bash rebuild.sh
```

`assemble_minimal_apk.py`는 재빌드 결과에서 Manifest/DEX만 가져오고 원본의 나머지 파일을 그대로 보존한다. `sign-build.sh`는 로컬 개인키로 정렬·서명·검증한다. 최종 결과를 다시 디코딩한 뒤 `verify_static.py`로 검사한다.

개인키는 `/workspace/paladog-work/private`에 별도로 보관되어 있으며 결과물·재현 자료 묶음에는 넣지 않는다. 같은 서명으로 후속 APK를 업데이트하려면 이 디렉터리를 안전하게 보존해야 한다. 개인키나 비밀번호를 공개하거나 APK와 함께 배포하지 말 것.

상세 근거는 `evidence/privacy.patch`, `evidence/static-validation.json`과 각 검토 보고서에 기록돼 있다.
